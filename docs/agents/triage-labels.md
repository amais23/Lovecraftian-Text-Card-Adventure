# Triage 標籤定義 (Triage Labels)

各項 Engineering Skills 是以五種標準的分流角色（Roles）進行溝通。本文件將這些角色對應至本儲存庫 Issue tracker 中所使用的實際標籤字串。

| 技能標準標籤 (Role) | 本專案使用之標籤 | 說明與意涵 |
| :--- | :--- | :--- |
| `needs-triage` | `needs-triage` | 維護者需要評估此任務 |
| `needs-info` | `needs-info` | 等待回報者提供更多補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格已完整定義，可直接交由 AI Agent 執行 |
| `ready-for-human` | `ready-for-human` | 需要由人工工程師進行實作 |
| `wontfix` | `wontfix` | 不會被執行或處理 |

當任何技能提及特定角色時（例如「標註為 AFK-ready 分流標籤」），請使用此對照表中的相應標籤字串。

若後續需要自訂標籤詞彙，直接編輯最右側欄位即可。

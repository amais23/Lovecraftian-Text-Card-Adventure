## Problem Statement

傳統文字冒險遊戲（Text Adventure）通常偏重純閱讀與靜態選項，缺乏緊湊且具深度的即時策略操作與博弈快感；而一般卡牌構築遊戲（如傳統 Roguelike Deckbuilder）則往往側重純數值對戰，缺少豐富的文學敘事沉浸感與世界觀厚度。

此外，市面上的克蘇魯神話遊戲大多將「理智值（Sanity）」作為與卡牌分離的次要計量條，無法直觀且具象地呈現調查員心智逐步遭到不可名狀之物蠶食、在理智崩潰邊緣掙扎的壓迫感。玩家渴望一款能將「克蘇魯恐怖敘事」與「實體卡牌操作策略」無縫融合的現代 Web 遊戲。

---

## Solution

打造一款結合**「克蘇魯文字冒險」**與**「卡牌策略對弈」**的現代化 Roguelike Web 遊戲：

1. **理智即牌庫（Sanity Deck）**：玩家牌庫中的剩餘卡牌數量直接等同於調查員的當前理智值。抽牌、遭受精神侵蝕或施展禁忌法術都會直接燃燒牌庫頂端卡牌。
2. **手動心智鎮定**：取消傳統抽空自動洗牌機制，玩家必須主動運用心智技能將棄牌洗回牌庫以延續心智。
3. **瘋狂極限逆轉（Madness State）**：當理智歸零（牌庫抽空）時，觸發「瘋狂極限狀態」，抽到的卡牌全部轉化為帶有毀滅性威力與嚴重反噬的「臨時強力黑色瘋狂卡」，提供背水一戰的刺激博弈。
4. **五色卡牌體系**：🔴紅戰鬥（物理傷害）、🟡黃技能（消耗精力、護甲與鎮定）、🟣紫魔法（消耗理智施展秘術）、⚪白真相（擴張牌庫/回補理智但伴隨代價）、⚫黑瘋狂（減益與瘋狂爆發）。
5. **雙層資源模型**：單場戰鬥局內考驗精力（每回合 3 點）與理智牌庫；戰後卡牌與理智重置回滿，但 25 點凡人肉體生命跨節點累積不自動恢復。
6. **隨機調查地圖**：Slay-the-Spire 風格節點推進，包含純文字秘識奇遇、常規戰鬥、精英戰、避難所與黑市。
7. **極致手感與美學**：Vite + React + TypeScript，深色古卷古典排版，上下分屏，具備動態扇形手牌展開、拖曳出牌與戰鬥日誌。

## User Stories

### 角色與開局
1. 作為調查員，我在開局時可以從「私家偵探（Edward Pierce）」與「秘術學者（Eleanor Vance）」兩個職業中選擇其一，以便體驗物理生存或秘術控場等截然不同的起始牌組與策略風格。
2. 作為調查員，我開局擁有 25 點初始生命值、每回合 3 點精力點數，以及包含 10~12 張職業專屬卡牌的理智牌庫，以便在高壓且有限的心智存量下展開冒險。

### 隨機調查地圖與探索
3. 作為調查員，我可以看見多分支的層級調查地圖，以便自主規劃探索路線。
4. 作為調查員，當我點擊「秘識奇遇（Mythos Event）」節點時，我能閱讀克蘇魯懸疑風格的沉浸文字，並在分支選項中做出抉擇，以便獲取線索、特殊卡牌或觸發檢定。
5. 作為調查員，當我進入「戰鬥節點」時，畫面能流暢過渡至戰鬥桌面，展示不可名狀敵人的形象與意圖預告。
6. 作為調查員，當我進入「避難所（Sanctuary）」節點時，我可以選擇包紮傷口恢復寶貴的肉體生命，或進行心智整理，以確保長線冒險能持續存活。
7. 作為調查員，當我進入「黑市」節點時，我可以使用旅途中收集到的古金幣（Ancient Obols）購買稀有卡牌或急救藥品。

### 卡牌對抗與理智牌庫機制
8. 作為調查員，我可以在戰鬥介面直觀看見牌庫中的剩餘卡牌數量，並明白這直接代表我當前的理智值（Sanity）。
9. 作為調查員，每回合開始時我能將手牌補抽至基準張數（4 張），以便規劃該回合的戰術。
10. 作為調查員，當回合結束時，我手中未打出的手牌會留在手中（Hand Retention），以便保留關鍵戰術卡牌而不被無端浪費。
11. 作為調查員，我打出黃色技能卡獲得的護甲值會跨回合累積保留，以便我在面對強大怪物蓄力攻擊時能預先佈防。
12. 作為調查員，當我遭受怪物的精神恐懼攻擊時，牌庫頂部的卡牌會被直接移至棄牌堆（理智侵蝕），讓我切身感受到心智被蠶食的壓迫感。
13. 作為調查員，我可以打出黃色心智技能卡（如深呼吸、鎮定劑），將棄牌堆中的卡牌洗回理智牌庫，從而使我的理智存量獲得回補。
14. 作為調查員，我可以打出紫色魔法卡，以直接消耗理智牌庫卡牌為代價，對敵人造成無視物理護甲的高額傷害。

### 瘋狂狀態與黑白卡機制
15. 作為調查員，當我的理智牌庫抽空（理智歸零）時，我不會立即死亡，而是觸發「瘋狂極限狀態（Madness State）」，以便進行最後的背水一戰。
16. 作為處於瘋狂狀態的調查員，我抽到的所有卡牌都會變為「臨時強力黑色瘋狂卡」，以便施展威力驚人但代價沉重的舊日暴走力量。
17. 作為調查員，我可以打出白色真相卡，藉由承受負面認知代價來強行擴張/回補牌庫卡牌，以便在瘋狂狀態中平復心智、脫離狂亂。
18. 作為處於瘋狂狀態的調查員，若我無法回補牌庫，我可以持續保持狂戰狀態直至將敵人消滅或肉體生命歸零，體驗極限博弈的戲劇性逆轉。

### 戰鬥呈現與手感操作
19. 作為調查員，我可以清楚看見敵人頭頂的「敵人意圖預告」，以便預判其下回合是物理攻擊、精神侵蝕還是詛咒防守。
20. 作為調查員，我可以在戰鬥畫面上半部閱讀以克蘇魯文學筆觸即時更新的「文字戰鬥日誌」，以便感受身歷其境的感官描寫。
21. 作為調查員，我的手牌會以精緻的弧形扇形排列，當游標滑過卡牌時卡牌會放大聚焦，並支援拖曳或點擊出牌，以便享受極致流暢的操作手感。

### 戰後結算與牌組構築
22. 作為調查員，在戰鬥獲勝後，我的常態卡牌會全數洗回理智牌庫，理智值重置回滿，而戰鬥中生成的臨時黑卡全數消散，以便迎接下一場全新心智對抗。
23. 作為調查員，在戰後我會面臨「隨機卡牌三選一」的構築獎勵，並可以選擇「跳過（Skip）」，以便精準控制牌庫厚度與抽牌濃度。
24. 作為調查員，在戰後我能獲得古金幣獎勵，但我知道受到的肉體生命傷害不會恢復，必須謹慎規劃後續路線。

## Implementation Decisions

### 1. 核心狀態機引擎 (Core Game State Machine)
- 採用純狀態機架構（Pure State Reducer），將遊戲全局狀態抽離：
  - `phase`: `'title' | 'map' | 'story' | 'combat' | 'reward' | 'gameover' | 'victory'`
  - `investigator`: `health` (預設 25), `maxHealth`, `stamina` (每回合 3), `maxStamina`, `armor`, `obols`, `occupation`
  - `sanityDeck`: `Card[]`（剩餘張數即等同於當前理智值）
  - `hand`: `Card[]`（手牌上限 7 張，回合開始補抽至 4 張）
  - `discardPile`: `Card[]`
  - `isMadness`: `boolean`（當 `sanityDeck.length === 0` 時為 `true`）
  - `currentEnemy`: `Enemy | null`
  - `battleLog`: `string[]`
  - `map`: `MapNode[][]`（多層隨機生成的節點矩陣）
  - `currentNode`: `MapNode | null`

### 2. 五色卡牌資料規格 (Card Schema)
- 包含字段：
  - `id`: 唯一標識
  - `name`: 卡牌名稱
  - `category`: `'combat' | 'skill' | 'magic' | 'truth' | 'madness'`（紅、黃、紫、白、黑）
  - `costType`: `'stamina' | 'sanity' | 'free'`
  - `costValue`: 消耗數值
  - `isTemporary`: `boolean`（是否為本場戰鬥限定之臨時卡）
  - `effects`: 效果陣列（造成傷害、獲得護甲、侵蝕牌庫、回補牌庫、抽牌、施加易傷/虛弱）
  - `icon`: 圖示代號（對應 `react-icons/gi`）
  - `flavorText`: 克蘇魯背景短文

### 3. 模組化文字劇本引擎 (Narrative Event Engine)
- 秘識奇遇以 JSON 節點形式組織，包含：
  - `title`, `text`（克蘇魯懸疑氛圍描寫）
  - `choices`: 包含 `label`, `requirements`（如理智/金幣門檻）, `outcome`（改變血量、獲取卡牌、扣減理智、切換戰鬥、轉移節點）

### 4. 前端視覺與動態系統 (Visual & Animation Layer)
- 使用 **Vanilla CSS** 配合 CSS 變數定義沉浸式暗黑克蘇魯主題色盤（古卷羊皮紙暗金、深海暗墨綠、枯骨白、鮮血紅、深淵紫）。
- 採用 **Framer Motion** 驅動手牌扇形排列（利用動態旋轉角度與 Y 軸位移）、拖曳出牌向上劃出感應線判定、血量與理智條受創震動效果。

## Testing Decisions

### 測試原則 (Testing Philosophy)
- 遵循「只測試外部行為與狀態轉移，不測試內部實作細節」的原則。
- 所有遊戲規則（包含洗牌、出牌、理智扣減、瘋狂轉換、戰後結算）皆為純資料轉換，必須具備 100% 確定性與可預測性。

### 核心測試接縫 (The Primary Seam)
- **單一最高測試接縫：Game State Reducer 介面**
  - 測試透過向 Reducer 發送 Action（如 `PLAY_CARD`, `END_TURN`, `ENTER_NODE`, `CHOOSE_STORY_OPTION`），驗證輸出的新狀態是否符合預期。
  - 測試模組包含：
    1. **理智扣減與精神侵蝕測試**：打出紫色魔法卡或受精神傷害時，`sanityDeck` 頂端卡牌精確減少，`discardPile` 增加。
    2. **手牌保留與護甲累積測試**：回合結束時手牌不被清空，護甲值不歸零，下回合正確補抽手牌至 4 張。
    3. **瘋狂狀態觸發與解除測試**：當 `sanityDeck` 抽空時觸發 `isMadness = true`，抽牌時生成臨時黑卡；當打出白卡將卡牌補回 `sanityDeck` 時，`isMadness` 解除。
    4. **戰後結算測試**：戰鬥勝利後，所有一般卡洗回 `sanityDeck`，臨時卡銷毀，而 `health` 保持受創數值不變。
    5. **地圖節點流轉測試**：玩家可依照合法路徑前進，無法跳躍無關節點。

## Out of Scope

1. **多人連線與 PvP 對弈**（首發版專注於極致的單人文字冒險與 PVE 對戰）。
2. **全 3D 角色模型與骨骼動畫**（採用 2D 高質感克蘇魯向量插圖與暗黑粒子/震動氛圍）。
3. **雲端帳號伺服器資料庫**（首發版採用瀏覽器 LocalStorage 儲存進度，支援即開即玩與離線遊玩）。
4. **自定義外部卡牌 MOD 編輯器**（首發版先專注打磨經典卡組與劇本平衡性）。

## Further Notes

- 開發時應特別注意字型選擇，優先載入 Google Fonts 的 **Noto Serif TC（思源宋體）** 與 **Cinzel**，保證中英文字體皆具備古典文學與神秘學典雅質感。
- 戰鬥日誌必須充滿克蘇魯文學風味（例如：「深潛者帶有魚腥味的利爪撕裂了你的風衣，造成 6 點傷害」、「舊印的光芒在虛空中灼燒，放逐了眼前的蠕動之影」）。

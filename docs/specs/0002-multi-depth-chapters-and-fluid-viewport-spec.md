## Problem Statement

當前遊戲僅具備一張 5 個層級的隨機節點地圖，調查員在擊破第一隻守關首領（修格斯幼體）後遊戲即告結束。整體探索流程與篇幅過於簡短，無法支撐長線策略構建的樂趣。此外，戰鬥後生命值絕不恢復的硬派設定在面對更長流程時需要合理的回血節奏；現有卡牌獎勵池單一無層次，首領戰缺乏足夠吸引力的高額獎勵與分支選擇；同時在較小尺寸視窗（如高度小於 768px 或比例較扁平的螢幕）下，各畫面會出現破壞沉浸感的外層上下捲軸，或者按鈕被擠出可視範圍。

---

## Solution

構建多深度章節探索體系、隱藏真結局解鎖機制、分階卡牌與越階首領獎勵，並全面封鎖外層捲軸、實現矮視窗下的深層原生自適應佈局：

1. **多深度章節架構（3+1 深度制）**：
   - 第一深度（阿卡姆封鎖區，16 節點）：守關首領「修格斯幼體」。
   - 第二深度（深潛者海蝕迷宮，16 節點）：守關首領「大袞深淵祭司」。
   - 第三深度（無底深淵祭壇，16 節點）：守關首領「原生巨型修格斯」。擊敗後若未滿足隱藏條件直接進入「普通結局」；若達成隱藏條件則撕開虛空裂隙進入第四深度。
   - 第四深度（星辰正位 · 拉萊耶核心，8 節點）：終局首領「克蘇魯星之眷族」，擊敗後達成「真結局」。

2. **首領戰利品、例外全額回血與深淵殘片隱藏真結局**：
   - 首領決戰肉體復甦：擊敗各深度守關首領後，身體生命值全額恢復（Heal to Full）。
   - 常規首領獎勵：50 古金幣 + 高階卡牌（第一深度首領越階給予 Tier 3+ 卡牌；第二深度首領給予專屬 Tier 4+ 強力卡牌）。
   - 隱藏真結局殘片：在第 1、2 深度擊敗首領時，可選擇「放棄常規獎勵」獲取不可打出的黑色瘋狂卡「深淵封印殘片·其一 / 其二」。擊敗第 3 深度首領時若已湊齊前兩枚，自動獲得其三並三卡共鳴融合成唯一的白色真相卡「完整的深淵古印」，同時解鎖第四深度，並獲贈專屬 Tier 4+ 卡牌與 50 古金幣。

3. **「完整的深淵古印」與終極首領神性斬殺**：
   - 在第四深度戰鬥中，身為真相卡的「完整的深淵古印」必定為起手第一張手牌（固有開局）。
   - 第四深度終極首領具備深淵神性，常規攻擊無法使其生命值低於 1 點（鎖定於 1 點）。
   - 唯有在終極首領血量降至 1 點的極限瞬間，「完整的深淵古印」解鎖釋放，打出即可引發星辰碎裂予以終極封滅，迎向真結局！

4. **全螢幕沉浸深度過渡黑幕演出**：
   - 各深度首領擊敗結算後，畫面淡入迷霧與純黑深淵幕布，伴隨心跳、深淵低語與打字機手記音效，描述調查員傷勢痊癒並深入下一層，隨後切換至下一深度全新地圖。

5. **絕對外層溢出封鎖與深層原生自適應佈局（方案 A）**：
   - 全面拔除所有外層容器的 `overflow-y: auto`，鎖定 `overflow: hidden`，徹底消除網頁式外層滾動條。
   - 僅保留合法內部容器平滑滾動（戰鬥日誌、早報、圖鑑、地圖畫布）。
   - 戰鬥手牌區、卡牌尺寸、HUD 面板、敵怪頭像與各類按鈕改採 CSS `clamp()` 與彈性縮放，確保在 600px~720px 矮螢幕下所有內容完整呈現，絕不裁切、字體極致銳利，且拖曳出牌座標判定 100% 精準。

## User Stories

### 多深度章節與節點推進
1. 作為調查員，當我開始冒險時，我進入由 16 個分支節點組成的「第一深度：阿卡姆封鎖區」地圖，以便在豐富的事件、遭遇與黑市中步步推進。
2. 作為調查員，當我完成第一深度的 16 節點探索並擊潰守關首領（修格斯幼體）後，我能看見全螢幕沉浸式黑幕過場，閱讀手記並聽見心跳與迷霧音效，隨後無縫進入由 16 個節點構成的「第二深度：深潛者海蝕迷宮」地圖。
3. 作為調查員，當我進入第二深度時，我會遭遇更具威脅的深海敵人（如深潛者幼嗣、深潛者長老）與全新環境奇遇，並在深處迎戰「大袞深淵祭司」。
4. 作為調查員，當我突破第二深度後，我能過渡至「第三深度：無底深淵祭壇」，探索 16 個高危節點並迎戰「原生巨型修格斯」。
5. 作為調查員，當我成功開啟隱藏路線進入「第四深度：星辰正位 · 拉萊耶核心」時，我會面對一張由 8 個極限節點組成的終局地圖，最後直面傳奇首領「克蘇魯星之眷族」。

### 首領獎勵、回血與隱藏真結局機制
6. 作為調查員，在擊敗任何深度的守關首領後，我的身體生命值會全額回滿，以便我有足夠體魄迎接下一深度的險惡環境。
7. 作為調查員，當我擊敗第一深度首領且選擇常規獎勵時，我可以獲得 50 古金幣，並越階抽取「第三深度以上（Tier 3+）」的高階強力卡牌。
8. 作為調查員，當我擊敗第一深度首領時，我可以選擇「放棄常規獎勵」，從而將黑色瘋狂卡「深淵封印殘片·其一」納入牌組。
9. 作為調查員，當我擊敗第二深度首領且選擇常規獎勵時，我可以獲得 50 古金幣，並抽取全遊戲僅在此處產出的「專屬第四階強力卡牌（Tier 4+ Exclusive）」。
10. 作為調查員，當我擊敗第二深度首領時，我可以選擇「放棄常規獎勵」，從而將黑色瘋狂卡「深淵封印殘片·其二」納入牌組。
11. 作為調查員，如果我在戰鬥中抽到「深淵封印殘片」，它顯示為無法打出，佔據我的手牌空間，讓我體驗到背負深淵真相的心智重壓。
12. 作為調查員，當我擊敗第三深度首領且未集齊前兩枚殘片時，系統不會發放任何卡牌或獎勵，而是直接觸發《阿卡姆早報》普通結局演出。
13. 作為調查員，當我在持有前兩枚殘片的情況下擊敗第三深度首領時，系統自動補齊第三殘片，三張黑色瘋狂殘片共鳴融合為單一張白色真相卡「完整的深淵古印」，同時撕裂虛空開啟第四深度，並補償發放專屬第四階強力卡牌與 50 古金幣。

### 終極古印與神性斬殺對弈
14. 作為進入第四深度的調查員，在與終極首領「克蘇魯星之眷族」對戰時，我的第一回合起手手牌必定包含「完整的深淵古印」。
15. 作為調查員，在終極首領生命值高於 1 點時，我手中的「完整的深淵古印」保持封印無法打出。
16. 作為調查員，當我使用各類常規戰鬥手段攻擊終極首領時，其生命值最多只能被扣至 1 點，無法直接以凡人武器擊殺。
17. 作為調查員，當終極首領生命值達到 1 點時，「完整的深淵古印」發光解鎖，我能將其打出觸發終極星辰封滅演出，斬殺舊日支配者並迎向《阿卡姆早報》真結局。

### 分階卡牌體系與商城探索
18. 作為調查員，在第一深度探索中，我能抽取和購買基礎與進階卡牌（Tier 1）。
19. 作為調查員，在第二深度探索中，戰鬥獎勵池與黑市商人會自動進化，提供更強力的 Tier 2 卡牌。
20. 作為調查員，在第三深度探索中，戰鬥獎勵池與黑市商人進一步進化為大師級 Tier 3 卡牌。

### 視窗無捲動與原生深層自適應
21. 作為在筆記型電腦或矮視窗（如 1366x768 或高度 600px~720px）上遊玩的調查員，我不會在遊戲外層看到任何瀏覽器式捲軸，整個遊戲完全固定在單一視界內。
22. 作為矮視窗下的調查員，在戰鬥畫面中，手牌、結束回合按鈕、各項 HUD 數值與敵怪資訊皆能完整展示且清晰可見，不被螢幕邊緣裁切。
23. 作為調查員，在任何螢幕解析度下向上拖曳卡牌打出時，卡牌跟隨游標精確無偏移，出牌釋放判定 100% 穩定流暢。
24. 作為調查員，在角色選擇頁面與戰後結算頁面中，所有按鈕與卡牌均直接陳列於畫面中央，不需要上下滾動即可完成點擊操作。
25. 作為調查員，在需要閱讀長文時，我依然可以在戰鬥日誌、圖鑑清單、早報頭條內文或縱向地圖畫布中使用平滑古典的內部滾動條。

## Implementation Decisions

1. **遊戲狀態機與多深度領域模型擴展**：
   - 在遊戲核心狀態中引入 `currentDepth`（1 至 4）、`unlockedDepths` 與 `abyssalSealsCollected` 追蹤欄位。
   - `InvestigationMap` 資料結構支援儲存各深度的專屬拓撲資訊與節點生成器。
   - 新增深度過渡狀態 `phase: 'depth_transition'`，承載沉浸手記過場演出。

2. **程序化多深度地圖生成器升級**：
   - 重構地圖生成演算法，支援生成包含 16 個節點的多層級 DAG（第 1、2、3 深度）與 8 個節點的終局 DAG（第 4 深度）。
   - 各深度具備專屬的敵怪型態池、奇遇事件池、避難所與黑市配置，連線拓撲確保所有起點皆能無死路連通至該深度守關首領。

3. **分階卡牌庫與首領專屬掉落邏輯**：
   - 擴充卡牌定義庫，新增 Tier 2、Tier 3 與專屬 Tier 4+ 卡牌群。
   - 新增不可打出的黑色瘋狂卡「深淵封印殘片·其一」、「深淵封印殘片·其二」與「深淵封印殘片·其三」。
   - 新增白色真相卡「完整的深淵古印」，賦予 `isInnateOpeningDraw: true` 標記與自訂解鎖條件判斷（僅當目標敵人具備不朽神性且生命值為 1 時解鎖可打出）。
   - 結算獎勵生成器依據當前深度以及是否為首領戰自動選取相應階級卡牌庫。

4. **神性不朽與古印處決對戰機制**：
   - 在敵怪資料結構中支援 `isImmortalGod: boolean` 屬性。在計算傷害扣除時，若敵怪具備神性不朽且當前未被打出古印，其生命值保底為 1。
   - 開局抽牌邏輯在第四深度對局開始時，確保將「完整的深淵古印」置於起手手牌第 1 張。
   - 古印打出時觸發特定終極處決動畫與音效，將敵怪生命值歸零並引導至真結局。

5. **全螢幕沉浸過渡黑幕演出元件**：
   - 建立 `DepthTransitionScreen` 元件，整合黑幕淡入淡出、迷霧粒子、心跳音效與打字機手記動畫。
   - 點擊「踏入深淵」或自動讀畢後觸發深度切換，呼叫地圖初始化與生命值全額回滿 Action。

6. **原生深層自適應佈局與滾動鎖定**：
   - 全域 CSS 拔除外層 `.title-screen-container`、`.occupation-selection-container`、`.reward-screen-container` 的 `overflow-y: auto`，強制全域 `overflow: hidden`。
   - 在戰鬥畫面、角色選擇與結算彈窗中全面應用 CSS `clamp()` 與矮視窗（`max-height: 768px` / `max-height: 650px`）自適應樣式，縮減留白與動態微調手牌高度。

## Testing Decisions

1. **良好測試之準則**：
   - 專注於測試外部可觀察之行為與狀態流轉，而非元件內部實作細節。
   - 驗證狀態機在各深度推進、首領戰勝回血、殘片收集融合、鎖血與斬殺之確定性行為。
2. **測試覆蓋之模組**：
   - **`gameReducer` 狀態轉換核心**：
     - 測試擊敗第一、二深度首領後生命值全額恢復。
     - 測試放棄獎勵領取殘片、三殘片自動融合成完整古印。
     - 測試第三深度首領戰勝後未集齊殘片進入普通結局、已集齊殘片開啟第四深度與獲得專屬獎勵。
     - 測試第四深度終極首領神性鎖血（生命值不低於 1）以及打出古印完成斬殺。
     - 測試卡牌分階與首領越階卡牌抽取邏輯。
   - **地圖生成演算法**：
     - 測試生成 16 節點（Depth 1~3）與 8 節點（Depth 4）的 DAG 拓撲連通性，保證所有分支皆能到達首領。
   - **UI 與元件渲染測試**：
     - 測試深度過渡畫面之渲染與切換。
     - 測試結算畫面上「放棄獎勵換取殘片」按鈕之互動與停用邏輯。
     - 測試各畫面容器具備 `overflow: hidden` 且無外層滾動條。
3. **現有測試範例 (Prior Art)**：
   - `src/engine/gameReducer.test.ts`
   - `src/App.test.tsx`
   - `src/components/RewardScreen.tsx` 相關測試

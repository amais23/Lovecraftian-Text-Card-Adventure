# 0007. 調查員職業與起始數值架構 (Starting Occupations & Metrics)

為突顯克蘇魯神話中「凡人面對未知恐懼時的脆弱與緊迫」，我們決定：

1. **初始生命值定為 25 點**：不採用傳統 RPG 動輒上百點的血量，使每次受創都極具威脅感。
2. **初始牌組張數定為 10~12 張（即初始理智值 10~12 點）**：緊湊的牌庫使得每一輪出牌與抽牌都面臨理智流失的倒數計時。
3. **依據開場調查員職業（Occupation）決定起始卡組構建**：
   - 例如：偏好物理與槍械的私家偵探（紅黃為主）、精通舊日典籍的秘術學者（紫白為主）、以及專注精神分析與心理防線的醫生（黃白為主）。

此決策奠定了高壓、快速反應且各職業策略風格迥異的 Roguelike 開局體驗。

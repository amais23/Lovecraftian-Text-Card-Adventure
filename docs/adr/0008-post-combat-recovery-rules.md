# 0008. 戰後結算與跨節點持久傷害機制 (Post-Combat Recovery Rules)

為區分「單場戰鬥局內戰術資源」與「整個調查冒險長線戰略資源」，我們決定：

1. **戰後卡牌與理智完全重置（Full Sanity & Deck Reset）**：
   - 戰鬥結束後，所有常駐一般卡（Permanent Cards）完整洗回理智牌庫，理智值回到該調查員目前牌組的總張數。
   - 所有戰鬥中產生的臨時卡（Temporary Cards，如瘋狂狀態抽出的臨時黑卡）全數自動消散。
   - 這保證了調查員在面對每一場新的遭遇戰時，都能有一整套完整的理智牌庫進行獨立博弈。

2. **肉體生命值不自動恢復（Persistent Health Damage）**：
   - 戰鬥中所受到的肉體傷害（Health）跨節點持續保留。
   - 25 點脆弱生命值必須依賴避難所（Sanctuary）的包紮、文字奇遇事件中的醫療決策或黑市藥品才能恢復。

此決策確立了清晰的雙層資源模型：理智代表「單場精神承受極限」，生命代表「長線生存肉體極限」。

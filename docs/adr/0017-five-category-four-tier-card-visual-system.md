# 0017. 五色四階卡牌雙維度視覺體系與邊框質感遞進規範 (Five-Category Four-Tier Card Visual System)

## 背景 (Context)
在實作 Issue #20（分階卡牌體系）後，專案引入了 Tier 1（基礎）、Tier 2（進階）、Tier 3（大師）與 Tier 4+（首領專屬神話）四層階級體系。
先前暫時將高階卡牌別名映射至 Tier 1 基礎卡插圖作為過渡方案，導致玩家在獲得弒神級王牌時產生嚴重的體驗落差與違和感。同時，卡牌界面（CardView）僅具備五色類別區分，缺乏直觀辨識卡牌階級的視覺維度。

## 決策 (Decision)

為達成高沉浸感與即時戰術辨識度，我們決定採用**「雙軌並行 (Dual-Track)」**設計：

### 1. 雙維度視覺架構
- **色彩維度（類別辨識）**：卡牌邊框主色調與底色依舊清晰維持紅（戰鬥）、黃（技能）、紫（魔法）、白（真相）、黑（瘋狂）五色體系。
- **材質與光效維度（階級辨識）**：在各類別主色之上，跨類別疊加統一的一致性邊框材質與光效遞進。
- **瘋狂卡特殊規則**：瘋狂卡作為理智崩潰時的深淵異化產物，**不設階級之分 (Non-tiered)**，始終保持混亂扭曲之原始深淵樣貌。

### 2. 四階邊框材質與光效階梯 (Tier Border Progression)
不採用破壞克蘇魯氛圍的數字或羅馬符號標籤，純粹依靠邊框材質紋理與流動光效實現直觀辨識：
- **Tier 1 (基礎/常規)**：素雅內斂平邊，維持經典金屬邊框，無額外光效。
- **Tier 2 (進階卡牌)**：精鋼/銀白雙線刻紋包角，微弱金屬冷光修飾。
- **Tier 3 (大師/高階)**：黃金/秘銀浮雕邊框，四角精細古印包覆，帶有緩慢典雅金芒呼吸光暈。
- **Tier 4+ (首領專屬弒神)**：舊印超維流光（Cosmic Prismatic Aura）、暗金超維浮雕與多維星塵微光，展現君臨神話的崇高魄力。

### 3. 高級插畫製作與占位符策略 (Artwork Roadmap & Placeholder Strategy)
- **占位符規範**：對於尚未完成專屬插畫的 Tier 2 與 Tier 3 卡牌，不再硬套 Tier 1 基礎卡圖，而是統一映射至專屬克蘇魯古卷風格的占位符（標註「還沒畫好 / 繪卷繪製中」），清晰傳達未完工狀態並保留玩家期待感。
- **插圖優先級**：優先以 4:3 高張力 AI 繪圖產出 **Tier 4+ 首領專屬神話卡（4 張）**，徹底解決「擊敗第二深度首領獲得王牌時的視覺落差」。

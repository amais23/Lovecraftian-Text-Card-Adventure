# 0005. 五色卡牌體系與臨時卡機制 (Five-Color Card System)

為深化克蘇魯風格的策略深度與哲學隱喻，我們決定採用鮮明的**五色卡牌分類體系**，並區分**「一般卡（Permanent）」**與**「臨時卡（Temporary）」**：

1. **🔴 紅色 - 戰鬥卡**：造成常規物理與肉體傷害。
2. **🟡 黃色 - 技能卡**：消耗精力點數（Stamina），包含護甲防禦、戰術過牌與手動心智鎮定（洗回棄牌）。
3. **🟣 紫色 - 魔法卡**：消耗理智（直接自理智牌庫頂端棄牌）施展的強大舊日秘術。
4. **⚪ 白色 - 真相卡**：代表窺視神話不可名狀的真相。雖然使牌庫張數增加（強行擴張理智上限），但大多伴隨嚴重的負面效應或抽牌污染，完美呼應克蘇魯「知曉越多，負擔越沉重」的核心哲學。
5. **⚫ 黑色 - 瘋狂卡**：不可打出或打出時帶來負面狀態的減益卡。

所有卡牌依其留存狀態分為持久留存的一般卡與僅在本場戰鬥生效的臨時卡。這套架構讓卡牌色彩直觀映射遊戲資源（精力 vs 理智 vs 牌庫容量），具備極高的策略辨識度與玩法張力。

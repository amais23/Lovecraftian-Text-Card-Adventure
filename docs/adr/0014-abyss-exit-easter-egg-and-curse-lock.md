# 0014. 深淵呢喃彩蛋遞進與屈服封印機制 (Abyss Exit Easter Egg & Curse Lock)

## 背景 (Context)

本遊戲為基於瀏覽器的沉浸式克蘇魯卡牌文字冒險。由於現代瀏覽器安全規範限制，網頁腳本無法主動透過 `window.close()` 關閉由使用者開啟的瀏覽器分頁。原先在主選單之「離開遊戲」按鈕設計為洛氏深淵呢喃彩蛋彈窗（提供「握緊理智 · 掙扎求生」與「屈服並沉入深淵」）。為進一步深化宇宙恐怖中「深淵無法逃脫、窺探深淵必遭反噬」的後設敘事（Meta-horror），需要建立具備多階段血液視覺遞進與終極封印的彩蛋機制。

## 決策 (Decision)

1. **五階段漸進式深淵沉淪 (Five-Stage Descent)**：
   - **第 1 次**：播放深淵瘋狂音效，彈窗關閉，畫面無血液（正常初次探索）。
   - **第 2 次**：螢幕周圍開始出現微量滲血與血滴蔓延特效（Blood Overlay Stage 1）。
   - **第 3 次**：血痕擴散加劇，視野周圍血跡漸濃（Blood Overlay Stage 2）。
   - **第 4 次**：血流如注，血幕遮蔽大部分視野，伴隨視線模糊效果（Blood Overlay Stage 3）。
   - **第 5 次**：觸發終極絕命演出，伴隨沉重深淵音效與劇烈螢幕震顫（Trauma Shake），全螢幕轉為純黑血幕並浮現鮮血大字「YOU DIED」。

2. **1~4 次階段之記憶態與重置條件 (Ephemeral vs. Persistent)**：
   - **純記憶體管理**：第 1~4 次的點擊計數與畫面血液效果僅存於 React 狀態記憶體中，**嚴禁寫入 localStorage**。
   - **重置條件**：當玩家點擊彈窗內之「握緊理智 · 掙扎求生」、點擊任何其他主選單選項（如開始調查、調查手冊、卡牌圖鑑、設定），或直接重新整理網頁時，計數立即歸零並消除所有血液特效。
   - **保留條件**：若玩家僅點擊彈窗右上角「X」關閉或點擊暗色遮罩背景關閉，血液特效保留於當前主選單畫面上，再次開啟「離開遊戲」時可接續累積。

3. **第 5 次終極「YOU DIED」封印 (Curse Lockout)**：
   - **完全阻斷**：全螢幕純黑血漬覆蓋，文字僅呈現經典魂系血紅大字「YOU DIED」，全畫面無任何關閉按鈕或互動按鍵，徹底終止當前遊戲程序。
   - **持久化快取**：寫入 `localStorage` 專屬鍵值（`arkham_abyss_dead: 'true'`）。
   - **無法繞過**：頁面重新整理或重啟分頁時，頂層（`App.tsx`）優先檢查該快取，若存在則直接常駐渲染「YOU DIED」全螢幕封鎖畫面，直到玩家手動清除瀏覽器快取/儲存空間為止。

## 影響 (Consequences)

- 強化玩家與克蘇魯世界觀的沉浸互動，將「離開遊戲」轉化為驚喜且具震懾力的後設恐怖體驗。
- 嚴格分離暫態與持久態，避免常規遊玩被誤觸污染，僅在深思熟慮連續 5 次主動沉入深淵時才觸發不可逆封印。

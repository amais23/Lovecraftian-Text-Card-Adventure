# 0011. 遊戲開局多階段過渡與阿卡姆早報結局流程 (Onboarding Flow & Arkham Gazette Ending Sequences)

為強化克蘇魯神話的文學沉浸感與電影感敘事體驗，我們決定重構現有單一直入的選角畫面，建立四階段開局動線與復古早報結算體系：

1. **開局四階段動線架構**：
   - **經典主選單 (Title Menu)**：以克蘇魯深淵氛圍呈現門戶，提供「開啟新調查」、「調查紀錄手冊」、「卡牌圖鑑」、「設定」與「離開（彩蛋）」。
   - **序章故事引導 (Prologue)**：透過 1920 年代阿卡姆失蹤案件剪報、委託信箋、心跳音效與打字機逐字浮現呈現世界觀（支援一鍵跳過）。
   - **職業選擇 (Occupation Selection)**：承接原有私家偵探（愛德華·皮爾斯）與秘術學者（艾蓮諾·凡斯）牌組與體質檢視。
   - **啟程動畫 (Departure)**：依據所選職業觸發專屬啟程演出（皮爾斯雨夜拔槍發動引擎 vs 凡斯翻開古籍銀鑰生輝），隨後無縫展開調查地圖。

2. **阿卡姆早報雙結局演出 (Arkham Gazette Ending)**：
   - 以 1920 年代《阿卡姆早報 (Arkham Gazette)》頭版頭條新聞動畫（報紙旋轉拍打桌面、血痕油墨、沉浸式新聞報導）取代原有的簡易彈窗。
   - **調查員殞命**：頭版報導「無名殘軀現身密斯卡托尼克河畔，警方稱純屬意外」，結算陣亡數據並提供重新調查。
   - **普通結局（封印暫歇）**：頭版報導「近郊廢棄修道院神秘異變暫歇，官方堅稱瓦斯洩漏，市民聲稱目睹夜空巨瞳」，營造「不可名狀僅暫時沉睡、末日危機未解」的未完成感，並為後續各 BOSS 專屬真結局保留架構空間。

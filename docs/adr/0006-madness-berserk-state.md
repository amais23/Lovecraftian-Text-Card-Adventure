# 0006. 理智歸零觸發瘋狂極限狀態 (Madness State & Black Cards)

傳統克蘇魯題材遊戲多將「理智歸零」視為直接失敗（Game Over）或單純的混亂無法行動。為提供強大的戲劇張力與極限逆轉策略，我們決定：**當理智歸零（牌庫抽空）時，遊戲不立即宣告失敗，而是進入「瘋狂狀態（Madness State）」**。

在瘋狂狀態下：
1. 調查員所抽取的卡牌全部轉化為**「臨時強力黑色瘋狂卡」**。
2. 這些瘋狂卡具備極度強大的傷害或超自然逆轉效果，但同時伴隨強烈的負面反噬（如消耗自身生命、加劇肉體創傷或限制下回合防禦）。
3. **平復與維持規則**：
   - 若能透過**白色真相卡**或其他手段將卡牌補充回牌庫（牌庫數量 > 0），調查員的心智獲得平復，隨即解除瘋狂狀態，恢復常態抽牌。
   - 若無法回補，調查員將在狂亂中持續戰鬥，直到將敵人全數消滅結束戰鬥，或自身生命值歸零死亡。

此決策確立了「自願壓低理智以換取瘋狂爆發」的高風險高回報玩法（Risk-Reward Loop），讓玩家在瀕臨精神崩潰的邊緣仍有背水一戰的策略操作空間。

# 0019. 3:5 哥德修長大卡牌規格與沉浸戰鬥介面去提示化架構 (Gothic Elongated 3:5 Card System & De-hinted Combat Interface)

## 狀態 (Status)

Accepted（取代 ADR-0013 與 ADR-0016 關於卡牌 5:7 舊比例、165px 緊湊手牌尺寸與雙重操作提示列之規範）

## 脈絡 (Context)

在先前 ADR-0013 與 ADR-0016 的設計中，為確保矮螢幕下之視界容納，卡牌長寬比定為 `5 / 7`（約 1 : 1.40），手牌高度基準設為 `clamp(165px, ...)`，且戰鬥畫面設有中央拖曳導引橫條（`.drag-drop-target-bar`）與卡牌內部底部提示列（`.card-play-prompt`）。

然而，當專案依照 ADR-0017 與 ADR-0012 導入 4:3 高張力 AI 專屬繪卷後，在 5:7 的寬胖卡牌中，插圖窗框即佔據了超過 53% 的卡牌垂直高度，導致下半部文字空間被極度壓縮（僅存不到 47%），卡名與效果敘述被迫限縮在 9~12px 之微小字級，多行戰術效果極易發生文字邊界截斷；同時雙重操作提示列佔據了約 40px 的寶貴垂直空間，且顯露「點擊或向上拖曳以打出」等技術操作詞彙，破壞了克蘇魯古典手記的純粹沉浸體驗。

## 決策 (Decision)

為徹底解決字體過小與文字容納問題，並達成主機級別的獨立卡牌藝術質感，我們決定：

### 1. 3:5 哥德修長塔羅長寬比 (Gothic Elongated 3:5 Aspect Ratio)

- 全局卡牌長寬比由 `5 / 7`（1 : 1.40）正式變更為 **`3 / 5`（1 : 1.667 經典修長塔羅比例）**。
- `--card-aspect-ratio: 3 / 5`，`--card-ratio-multiplier: calc(3 / 5)`。
- **插圖與文字黃金配比**：4:3 典藏插圖維持 100% 寬度置於卡牌上半部（高度約佔卡牌總高 45%），下半部保留超過 **55%** 的充裕垂直縱深專供大字號文字排版，徹底杜絕文字擠壓。

### 2. 戰鬥介面去提示化 (De-hinted Combat Interface)

- **全面拔除雙重操作提示**：
  1. 徹底移除戰鬥中央的 `.drag-drop-target-bar`（「點擊或向上拖曳以打出卡牌」橫條）。
  2. 徹底移除每張卡牌內部的 `.card-play-prompt`（「點擊或上拖打出」、「精力不足」、「發動狂擊」等提示列）。
- **去技術化與空間釋出**：釋出近 40px 之垂直視界空間全數挹注給手牌區與文字展示；卡牌互動依循現代成熟卡牌遊戲之本能交互（直覺點擊或向上拖曳即可出牌），免除繁複提示文字，回歸 1920 年代古卷純粹沉浸。

### 3. 卡牌整體面積加大與自適應分配 (Expanded Card Dimensions)

- **戰鬥手牌區**：
  - 卡牌高度大幅提升為 **`clamp(210px, 30dvh, 300px)`**（卡牌面積擴增 40%～50%）。
  - 手牌區高度同步提升為 **`clamp(220px, 31dvh, 310px)`**。
  - 手牌中心錨定偏移值（`margin-left`）等比同步更新。
- **獨立卡牌（圖鑑 / 職業選擇 / 詳情特寫）**：
  - 卡牌高度大幅提升為 **`clamp(290px, 38dvh, 380px)`**，展現神話王牌與典藏手記之磅礡氣勢。
- **戰後獎勵選牌**：
  - 卡牌高度調整為 **`clamp(200px, 28dvh, 275px)`**。
- **上半部動態收斂**：
  - 上半部敵怪舞台與戰鬥日誌利用 `flex: 1; min-height: 0;` 自動等比收斂，嚴格維持 ADR-0016「600px 矮螢幕無外層捲軸」之沉浸鐵律。

### 4. 醒目典雅文字體系 (Prominent Gothic Typography)

- **卡牌名稱 (`.card-title-banner`)**：
  - 字級提升為 **`clamp(0.95rem, 9.5cqw, 1.3rem)`**（約 15px ～ 18px），金色羊皮紙高對比陰影，字體雄渾醒目。
- **規則效果敘述 (`.card-effect-desc`)**：
  - 字級提升為 **`clamp(0.82rem, 8.2cqw, 1.12rem)`**（約 13px ～ 16px），行高 `1.35`，搭配高對比暗夜半透明底板，多行效果文本清晰好讀且絕不裁切。
- **標籤與敘事分層**：
  - 狀態徽章（`.card-tag-badge`）放大為 `clamp(0.55rem, 5.5cqw, 0.7rem)`。
  - 戰鬥手牌常態聚焦戰術大字；小說風格背景敘事（Flavor Text）在卡牌圖鑑、選角特寫及懸停展示時完整呈現。

## 影響 (Consequences)

- 徹底消除卡牌文字過小、看不清或邊緣被裁切的痛點。
- 戰鬥介面大幅去雜訊化，視覺空間更聚焦於克蘇魯神話卡牌美術與戰術抉擇。
- 建立統一的 3:5 哥德修長視覺標準，所有相關文檔與組件規範保持同步。

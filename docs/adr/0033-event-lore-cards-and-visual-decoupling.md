# 0033. 秘識奇遇專屬卡牌與全域美術去借用架構 (Event Lore Cards & Full Visual Decoupling Architecture)

## 狀態 (Status)

Accepted（擴充 ADR-0012、ADR-0017、ADR-0019、ADR-0024 與 ADR-0032，全面達成戰術卡牌與黑市醫療物資之 100% 專屬視覺解耦）

## 脈絡與決策動機 (Context & Trade-offs)

在現有全域卡牌與節點內容體系中，雖然 64 張常態典藏卡牌（起始牌組、Tier 1~4 獎勵卡、3 張基礎瘋狂卡、3 張深淵殘片與古印）已具備獨立繪圖，但隨著近期深入開發與節點動態庫擴充，浮現了多處視覺借用（Fallback & Alias Reuse）與代碼歷史殘留問題：

1. **核心機制黑卡借用其他卡圖**：
   - 【深淵詛咒】（遺物秘閣【破除古神封印】獲得的無法打出黑色瘋狂卡）長期借用【深淵狂嘯】繪卷。
   - 【星辰碎裂之囈語】（第四深度首領戰克蘇魯星之眷族【神性不滅】污染生成的臨時黑色瘋狂卡）未註冊獨立插畫，直接退避至【盲目爪擊】。
2. **秘識奇遇（Mythos Events）專屬卡牌嚴重退避**：
   - 透過文字事件獲取的 7 張專屬卡牌（【水下爆破】、【潮汐之音】、【原形觸鬚】、【太古幾何密卷】、【星之眷族印記】、【維度漫步】、【終焉覺悟】）未收錄於 `CARD_ARTWORKS_REGISTRY`，戰鬥中直接退避顯示為【左輪射擊】、【舊日殘頁】與【就地掩蔽】等基礎圖檔，破壞文字冒險的沉浸感。
   - 此 7 張奇遇卡缺乏標準化克蘇魯敘事背景（`flavorText`）、規範關鍵字（如【消耗】）與標準狀態印記標註。
3. **黑市動態醫療補給品借用戰鬥技能卡插圖**：
   - 黑市 6 款醫療物資（嗎啡注射劑、酒精繃帶、戰地醫療箱、抗逆血清、復甦針劑、聖水金樽）目前借用【醫療鎮定劑】、【應急急救包】與【遠古護身符】的卡圖，造成「醫療消耗品」與「理智手牌」界線模糊。
4. **程式碼內部殘留過期 dummy 路徑**：
   - 多處卡牌定義檔案中殘留 81 處歷史 placeholder URL（如 `/cards/combat/card_revolver.webp`），存在維護隱患。

經由架構質詢（Grilling Session），我們決定：**全面終結圖片借用與退避，將 7 張秘識奇遇卡牌正式登錄為「秘識奇遇專屬卡（Event Lore Cards）」並將卡牌圖鑑擴充至 73 張；為黑市醫療品建立「典藏藥品插畫框（Apothecary Artifact Frames）」；並清理全域代碼硬編碼路徑。**

## 決策內容 (Decision)

### 1. 秘識奇遇專屬卡牌體系與圖鑑擴充 (Event Lore Cards & 73-Card Compendium)

- **正式註冊為「秘識奇遇專屬卡」**：
  - 【水下爆破】（紅色戰鬥，Tier 2，【消耗】）
  - 【原形觸鬚】（紅色戰鬥，Tier 2）
  - 【星之眷族印記】（黃色技能，Tier 3）
  - 【維度漫步】（黃色技能，Tier 3）
  - 【潮汐之音】（白色真相，Tier 2）
  - 【太古幾何密卷】（白色真相，Tier 2）
  - 【終焉覺悟】（白色真相，Tier 4）
- **全面對齊 ADR-0019 與 ADR-0024 規範**：
  - 補齊原汁原味之克蘇魯神話背景敘事文字（`flavorText`）。
  - 嚴格標註標準中括號【】與生命週期關鍵字（如【消耗】、【保留】）。
  - 全域卡牌圖鑑（`CANONICAL_COMPENDIUM` 與 `ALL_CARD_ARTWORKS`）正式由 64 張擴充為 **73 張**，100% 具備專屬獨立插畫。

### 2. 五色專屬畫風契約嚴格貫徹 (Category Aesthetics Consistency)

新生成之 9 幅 3:5 卡牌繪卷嚴格遵守 ADR-0012 / ADR-0017 所定義之美學契約：
- **紅色戰鬥卡（【水下爆破】、【原形觸鬚】）**：維持「可愛卡通風格（Cute Cartoon）」，以強烈的荒誕黑色幽默反差呈現爆炸與深淵黑泥觸鬚。
- **黃色技能卡（【星之眷族印記】、【維度漫步】）**：維持「1920 年代復古寫實風格（1920s Dark Gothic Realism）」，展現凡人調查員在昏暗油燈下的生存技藝與時空步伐。
- **白色真相卡（【潮汐之音】、【太古幾何密卷】、【終焉覺悟】）**：維持「冰冷崇高宇宙恐怖（Cosmic Horror）」，描繪多維星軌、天體幾何與宇宙神性天眼。
- **黑色瘋狂卡（【深淵詛咒】、【星辰碎裂之囈語】）**：維持「深淵異化血肉風格（Visceral Abyss）」，描繪黑曜石古印崩解與星辰碎裂之狂亂觸鬚。

### 3. 黑市典藏藥品插畫框 (Apothecary Artifact Frames)

- 針對黑市商人販售的 6 款醫療品（軍用嗎啡注射劑、高純度酒精繃帶、高級戰地醫療箱、深海抗逆血清、禁忌復甦針劑、聖所聖水金樽），全面配置 1:1 正方形復古寫實醫療靜物插圖（`/supplies/supply_*.png`）。
- 於 `MarketScreen` 貨架物品卡中獨立配置「典藏藥品插畫框」，與常規 3:5 戰鬥卡牌明確區隔，消除「購買後未進入手牌庫」的交互疑惑。

### 4. 代碼路徑收斂與單一真理源

- 清理 `investigator/rewards.ts`、`occultist/rewards.ts`、`neutral/common.ts` 與 `special/madness.ts` 中 81 處過期硬編碼路徑，確保卡牌定義檔與 `getCardArtwork()` 解析結果 100% 一致。
- 移除 `CARD_NAME_ALIASES` 中不再需要的 fallback 別名（如 `'深淵詛咒': '深淵狂嘯'`）。

## 影響與驗證 (Consequences & Verification)

### 正面影響 (Positive Impact)
- 徹底消除戰鬥出牌與手牌預覽時的重複圖片問題，極大增強探索奇遇事件與獲得專屬卡牌的正向反饋。
- 黑市醫療物資具備專屬精緻插圖，貨架沉浸感顯著提升。
- 卡牌圖鑑達到 73 張完全獨立繪卷，達成真正的「100% Dedicated Artwork」。
- 程式碼消除歷史殘留的 dummy 路徑，架構更加強健純粹。

### 驗證依據 (Verification)
- 單元測試 `cardArtworks.test.ts` 驗證：
  1. `ALL_CARD_ARTWORKS.length === 73`，且無任何重複圖片路徑。
  2. 73 幅卡牌圖片與 6 幅黑市藥品圖片實體存在於 `public/cards/` 與 `public/supplies/`。
  3. 0 張卡牌退避至 generic fallback。
- 執行 `npm run test:run`、`npm run typecheck` 與 `npm run lint` 全數通過。
